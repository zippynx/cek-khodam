# Cek Khodam

A simple web application that generates a fictional **Khodam** based on the user's name. Built with **HTML, CSS, and Vanilla JavaScript**, featuring a modern interface, smooth animations, local history, and image export functionality.

> **Disclaimer:** This project is created for entertainment purposes only.

---

## Features

- Deterministic Khodam generation
- Responsive user interface
- Typewriter animation
- Loading animation
- Save result as PNG
- Local search history
- Toast notifications
- Reset and clear input

---

## Technologies

- HTML5
- CSS3
- JavaScript (ES6)
- html2canvas
- Phosphor Icons
