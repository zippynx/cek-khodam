# 🔮 Cek Khodam Nusantara v1.0

Selamat datang di portal mistis digital! **Cek Khodam** adalah aplikasi web seru-seruan buat kamu yang penasaran kira-kira "entitas" apa sih yang selama ini nemenin kamu di dunia gaib. 

Gak perlu pakai kemenyan atau kopi pahit, cukup ketik nama, portal mistis bakal kebuka otomatis! ✨

---

## 🌟 Kenapa Cek Khodam Ini Beda?

Bukan cuma sekadar *random generator*, versi ini punya beberapa fitur "sakti":

- **💎 Visual Premium (Dark Gold Theme):** Desain *dark mode* elegan dengan sentuhan emas dan ungu. Gak malu-maluin kalau di-screenshot!
- **🧠 Algoritma Deterministik:** Hasilnya bukan asal acak. Nama yang sama bakal selalu dapet khodam yang sama. Jadi kalau dapet "Indomie Goreng", ya bakal tetep itu selamanya!
- **⚡ Ikonik & Modern:** Menggunakan *Phosphor Icons* biar tampilan tetep bersih dan profesional. Gak ada lagi emoji bawaan HP yang beda-beda bentuknya.
- **📱 Siap Pamer:** Ada fitur **Share** biar kamu bisa langsung pamer hasil terawangan ke WhatsApp atau sosial media lainnya.

---

## 🛠️ Teknologi di Balik Portal

Project ini murni pake "bumbu" dasar web dev, jadi ringan banget:
- **HTML5:** Struktur portal yang rapi.
- **CSS3:** *Dark Glassmorphism* dengan animasi *glowing* dan *floating*.
- **Vanilla JavaScript:** Logika *hashing* untuk nentuin khodam biar gak berubah-ubah.
- **Phosphor Icons:** Untuk *vibe* ikon yang lebih premium.

---

## 🚀 Cara Pakai

Gampang banget, gak perlu ritual aneh-aneh:
1. Clone atau download repo ini.
2. Buka file `index.html` di browser kesayangan kamu.
3. Ketik nama kamu di kolom "Nama Kamu".
4. Klik tombol **Ungkap Khodam**.
5. Tunggu portal kebuka (simulasi loading portal mistis).
6. BAM! Khodam kamu bakal muncul beserta artinya yang mendalam (atau kocak).
